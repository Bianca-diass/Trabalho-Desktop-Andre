# Trabalho Desktop - André

Aplicação Desktop desenvolvida em Java como parte de um projeto/trabalho académico.

## 🚀 Tecnologias Utilizadas

* **Java** (100%)
* **NetBeans IDE**
* **Apache Ant** (Gestor de automação de compilação)

## 📁 Estrutura do Projeto

* `src/` - Código-fonte da aplicação Java.
* `Lib/` - Bibliotecas e dependências externas (`.jar`).
* `nbproject/` - Configurações do projeto específicas do NetBeans IDE.
* `build.xml` - Ficheiro de configuração do Apache Ant para compilação.
* `manifest.mf` - Ficheiro de manifesto do projeto.
